# iPhone ホームに家計簿ウィジェットを出す（Scriptable）— 貼り付け手順

mywork#967。今月の **収入・支出・合計** を iPhone のホーム画面に出す。小・中サイズに対応。
トークンや金額はこのファイル・git・Issue に書かない。

## しくみ
- API: `GET https://kakebo-omega.vercel.app/api/v1/widget/summary`（読み取り専用）
  - `Authorization: Bearer <WIDGET_TOKEN>` が一致したときだけ、`WIDGET_USER_ID` の人の今月の数字を返す。トークンなし・違うトークン・未設定は 401
  - 返すのは `month`・`today`・`income`・`expense`・`balance` だけ（カテゴリ別などは出さない）。定義は画面と同じ（支出＝購入−返金、振替等除外、今月は今日まで）
- ウィジェット: `scripts/widget/kakebo-widget.js`（Scriptable 用）。トークンは iPhone の Keychain に保存。30分ごとに更新を頼む（実際の間隔は iOS が決める）。タップで家計簿が開く

## 1. サーバー側（AI が行う。本人の OK 後）
1. トークンを作る（Mac で）: `openssl rand -base64 32 | tr -d '\n=+/' | pbcopy` — クリップボードに入る。画面・ログに出さない
2. Vercel の本番に2つ入れる（`app/` で、個人アカウント設定）
   - `pbpaste | vercel env add WIDGET_TOKEN production --global-config ~/.config/vercel-personal`
   - `printf %s <本人のユーザーID> | vercel env add WIDGET_USER_ID production --global-config ~/.config/vercel-personal`（`OWNER_USER_IDS` と同じ ID）
3. マージして本番に出す（env は次のデプロイから効く）
4. 確かめる（1回だけ）: `curl -s -o /dev/null -w '%{http_code}\n' https://kakebo-omega.vercel.app/api/v1/widget/summary` → `401`
5. トークンを本人の iPhone へ: 1Password 等のパスワード管理アプリに入れる、または AirDrop のメモで渡してすぐ消す。Issue・LINE・メールには貼らない

## 2. iPhone 側（本人）
1. App Store で **Scriptable**（無料）を入れる
2. Scriptable を開き、右上の **＋** → 新しいスクリプト。名前を「家計簿」にする
3. `scripts/widget/kakebo-widget.js` の中身を全部コピーして貼る（GitHub の PR の Files changed → ファイル右上の「…」→ View file → Raw を長押しでコピー）
4. 右下の ▶︎ で一度実行 → 「kakebo のトークン」の欄にトークンを貼って **保存** → 中サイズの見本が出れば OK
5. ホーム画面を長押し → 左上の **＋** → Scriptable → 小か中を選んで追加
6. 追加したウィジェットを長押し → **ウィジェットを編集** → Script で「家計簿」を選ぶ

## 困ったとき
| 表示 | 直し方 |
|---|---|
| 「Scriptable で一度開いてトークンを入れてください」 | 手順 2-4 をやる |
| 「トークンが違います」 | Scriptable でスクリプトを開いて ▶︎ → Keychain から消えるので、もう一度 ▶︎ で入れ直す |
| 「取得に失敗（500 等）」 | 家計簿側の不具合。開発部に連絡 |
| 数字が古い | iOS の更新待ち。Scriptable で ▶︎ するか、少し待つ |

## トークンを替えるとき（漏れたかも、など）
1 の手順でトークンを作り直して `vercel env rm WIDGET_TOKEN production` → `add` → 再デプロイ。iPhone は「トークンが違います」の手順で入れ直す。
止めたいときは `WIDGET_TOKEN` を消して再デプロイすれば 401 になる。
